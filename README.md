# Love Garden 🌸

Love Garden is a playful interactive web experience where every click grows a flower in a dreamy animated garden.

The page starts as a soft pastel garden and gradually fills with colorful flowers, floating sparkles, butterflies, bees, and sweet love notes. A day/night toggle changes the mood of the scene, and the garden stats update live as the user interacts.

## Features

- Single-file HTML app
- Click anywhere to grow flowers
- Random flower styles and heights
- Floating love messages that appear after a few blooms
- Day and night mode toggle
- Live garden stats:
  - Flowers count
  - Love messages count
  - Garden level
- Decorative animated elements:
  - Sparkles
  - Butterflies
  - Bees
  - Clouds
  - Sun / moon scene

## Built With

- HTML
- CSS
- Vanilla JavaScript

No frameworks, no external dependencies, and no build step required.
